# Stock Portfolio Tracker

## About the Project
The Stock Portfolio Tracker is a beginner-friendly Python project that helps users manage their stock investments and calculate their total investment value. The given price of shares are sample values used here.

## Features
- Displays available stocks and their prices.
- Allows users to enter stock names and quantities.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Saves portfolio details in a CSV file.

## Technologies Used
- Python
- CSV Module
- Dictionary
- Loops and Conditional Statements

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python stock_tracker.py
```


## Available Stocks
- APPLE
- TESLA
- GOOGLE
- MICROSOFT
- AMAZON

**Note:** Stock prices are predefined sample values and are not live market prices.

## Output
The program calculates the total investment value and saves the portfolio information in `portfolio.csv`.
